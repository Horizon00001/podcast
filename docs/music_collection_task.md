# Podcast 背景音乐收集任务

## 任务目标

为 Podcast 收集开头、过渡、结尾三类背景音乐。

## 音乐要求

### 1. 开头音乐 (Opening)
- **用途**：节目开始时使用
- **时长**：10-15 秒
- **风格**：欢快、启发性强、吸引听众
- **格式**：MP3

### 2. 过渡音乐 (Transition)
- **用途**：章节之间平滑过渡
- **时长**：5-10 秒
- **风格**：轻柔、流畅、不突兀
- **格式**：MP3

### 3. 结尾音乐 (Closing)
- **用途**：节目结束时使用
- **时长**：15-30 秒
- **风格**：温馨、回味感、给听众留下好印象
- **格式**：MP3

## 文件存放位置

项目路径：`/home/default/Projects/podcast/assets/audio/`

```
assets/audio/
├── opening/       # 开头音乐
├── transition/   # 过渡音乐
└── closing/      # 结尾音乐
```

## 文件命名规范

```
# 开头音乐
opening/<编号>_<风格/描述>.mp3

# 过渡音乐
transition/<编号>_<风格/描述>.mp3

# 结尾音乐
closing/<编号>_<风格/描述>.mp3
```

示例：
- `opening/01_upbeat_technology.mp3`
- `transition/02_soft_piano.mp3`
- `closing/03_warm_reflection.mp3`

## 推荐音乐来源

1. **免费商用音乐网站**
   - Pixabay Music (https://pixabay.com/music/)
   - Free Music Archive (https://freemusicarchive.org/)
   - Bensound (https://www.bensound.com/)
   - Artlist (https://artlist.io/) (免费区)
   - Epidemic Sound (https://www.epidemicsound.com/) (免费区)

2. **YouTube 音频库**
   - YouTube Audio Library (https://music.youtube.com/)

3. **CC0 音乐网站**
   - Musopen (https://musopen.org/)
   - Incompetech (https://incompetech.com/)

## 注意事项

1. 确保音乐**可商用**，无版权问题
2. 检查音乐授权条款是否允许在 Podcast 中使用
3. 推荐收集每个类型 **3-5 个候选**，不同风格
4. 如使用需标注来源和授权类型

## 交付内容

1. 下载的音乐文件（MP3 格式）
2. 每个文件的来源链接
3. 授权类型说明（CC0 / Royalty Free / 付费购买等）
