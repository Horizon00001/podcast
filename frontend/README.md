# Frontend Quick Reference

This React + Vite app lives in `frontend/`.

## Run

```bash
npm install
npm run dev
```

## Check

```bash
npm run lint
npm run build
npm test
```

## Notes

- Main router: `src/router/index.tsx`
- Main API client: `src/services/api.ts`
- App routes include `/`, `/podcasts/:id`, `/generate`, `/subscriptions`, `/models`, `/settings`, `/likes`, and `/favorites`
- Root project docs live in `../README.md`
